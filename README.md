# Boredom Destroyer

Boredom Destroyer is a fully responsive web app built with HTML, CSS, and JavaScript. It blends BTS-inspired purple energy, Marvel-style playful roasts, neon disco effects, and interactive mini-games into a modern glassmorphism experience.

## Features

- Landing screen with an escaping NO button and an animated YES transition
- Dashboard with animated cards, floating effects, and a mood booster featuring 100+ positive messages
- Guess The Lyrics game with 20 fictional BTS-style lyric challenges
- Marvel Roast Generator with more than 100 playful family-friendly roasts
- Disco Room with pulsing text, animated laser vibes, and clickable light bursts
- BTS Vibe Matcher quiz with 5 personality questions and an animated reveal
- Smooth spider-web screen transitions and responsive mobile-first layout

## Installation

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. No additional build tools are required.

## Deployment

- Host the app on any static website provider: GitHub Pages, Netlify, Vercel, or your own server.
- Upload the full repository and point the site to `index.html`.

## Project Structure

- `/assets` - placeholder image and icon folders
- `/css/style.css` - main styles and responsive layout
- `/js/app.js` - application navigation and game logic
- `/js/games.js` - lyrics, roast, and mood booster data
- `/js/quiz.js` - BTS vibe quiz questions and result profiles
- `/js/effects.js` - particle, spark, and transition animations
- `index.html` - main landing page and game screens
